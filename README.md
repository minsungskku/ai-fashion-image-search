# AI 기반 의류 이미지 유사도 및 스타일 검색 시스템

## 프로젝트 소개
이미지를 기반으로 유사한 의류를 검색하는 웹 시스템입니다.

## 주요 기능
- 이미지 업로드 기반 검색
- CNN 기반 feature extraction
- cosine similarity 기반 유사도 계산
- 스타일 기반 검색

## 기술 스택
- Python
- Flask / FastAPI
- CNN (pretrained model)
- Vector similarity search

## 개발 예정
- 데이터 수집
- 모델 적용
- 웹 인터페이스 구현
